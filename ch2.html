01
HTML Basics — Tags, Elements & Attributes
أساسيات HTML — الوسوم، العناصر والسمات
English

HTML stands for HyperText Markup Language. It's not a programming language — it's a markup language. You use it to describe the content of a page using tags. Every visible element on a webpage is an HTML element.

العربية

HTML اختصار لـ HyperText Markup Language. إنها ليست لغة برمجة — بل لغة وسوم. تستخدمها لوصف محتوى الصفحة باستخدام الوسوم. كل عنصر مرئي في صفحة الويب هو عنصر HTML.

يبدأ العنصر. مثال: <p>

Closing Tag
وسم الإغلاق

ينهي العنصر. يحتوي دائماً على / قبل الاسم.

⚡

Some tags have no content and close themselves: <img> <br>

بعض الوسوم بلا محتوى وتغلق نفسها: مثل img وbr وinput.

02
Page Structure — head, body & meta tags
هيكل الصفحة — head وbody والوسوم الوصفية
English

Every HTML file follows the same structure. Think of it like a human body: the <head> is the brain (invisible settings), and the <body> is what people actually see.

العربية

كل ملف HTML يتبع نفس الهيكل. فكّر فيه كجسم الإنسان: <head> هو الدماغ (إعدادات غير مرئية)، و<body> هو ما يراه الناس فعلاً.

index.html — Boilerplate Template / القالب الأساسي
<!-- Every HTML file starts with this --> <!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>My First Page</title> <!-- CSS goes here --> <link rel="stylesheet" href="css/style.css"> </head> <body> <!-- Everything visible goes here --> <h1>Hello, World!</h1> <!-- JS goes at the bottom --> <script src="js/script.js"></script> </body> </html>
🧠
What goes in <head>?
ماذا يوضع في head؟

• <title> — tab name in browser
• <meta charset> — character encoding
• <meta viewport> — mobile scaling
• <link> — connect CSS file
• SEO description, favicon link

• title — اسم التبويب في المتصفح
• meta charset — ترميز الأحرف
• meta viewport — المقياس على الجوال
• link — ربط ملف CSS
• وصف SEO ورابط الأيقونة

👁️
What goes in <body>?
ماذا يوضع في body؟

Everything the user sees:
• Text: headings, paragraphs
• Media: images, video, audio
• Navigation, buttons, forms
• All layout and content

كل ما يراه المستخدم:
• النصوص: عناوين وفقرات
• الوسائط: صور وفيديو وصوت
• التنقل والأزرار والنماذج
• كل التخطيط والمحتوى

💡

In VS Code, type ! inside an empty HTML file and press Tab or Enter. It instantly generates the full boilerplate. This is an Emmet shortcut!

في VS Code، اكتب ! داخل ملف HTML فارغ ثم اضغط Tab أو Enter. سيولّد القالب الكامل فوراً. هذا اختصار Emmet!

03
Text Elements — Headings, Paragraphs & Lists
عناصر النص — العناوين، الفقرات والقوائم
English

Text is the backbone of every webpage. HTML gives you specific tags for each type of text — headings tell the browser "this is important", paragraphs hold body text, and lists organize items clearly.

العربية

النص هو العمود الفقري لكل صفحة ويب. يمنحك HTML وسوماً محددة لكل نوع من النصوص — العناوين تخبر المتصفح "هذا مهم"، والفقرات تحمل نص الجسم، والقوائم تنظم العناصر بوضوح.

⚠️

Use headings in order. Never skip from h1 to h4. Search engines and screen readers depend on heading hierarchy. Every page should have only one h1.

استخدم العناوين بالترتيب. لا تقفز من h1 إلى h4. محركات البحث وقارئات الشاشة تعتمد على تسلسل العناوين. يجب أن تحتوي كل صفحة على h1 واحد فقط.

04
Links & Images
الروابط والصور
English

Links connect the web together — without them, every page would be an island. Images make pages visual and engaging. Both are essential HTML skills you'll use in every single project.

العربية

الروابط تربط الويب ببعضه — بدونها كل صفحة ستكون جزيرة. الصور تجعل الصفحات مرئية وجذابة. كلاهما مهارات HTML أساسية ستستخدمها في كل مشروع.

Links — <a> tag / الروابط
<!-- External link / رابط خارجي --> <a href="https://google.com" target="_blank">Open Google</a> <!-- Internal link (another page) / رابط داخلي --> <a href="about.html">About Us</a> <!-- Link to a section on same page / رابط لقسم في نفس الصفحة --> <a href="#contact">Jump to Contact</a> <!-- Email link / رابط بريد إلكتروني --> <a href="mailto:hello@example.com">Send Email</a>
AttributeValueWhat it doesالوظيفة
hrefURL or pathThe destination linkالرابط الوجهة
target="_blank"_blankOpens in new tabيفتح في تبويب جديد
titletextTooltip on hoverتلميح عند المرور
Images — <img> tag / الصور
<!-- Basic image from your folder / صورة من مجلدك --> <img src="images/photo.jpg" alt="A description of the image" width="400" > <!-- Image from the internet / صورة من الإنترنت --> <img src="https://picsum.photos/400/200" alt="Random placeholder image" > <!-- Clickable image (link + image) / صورة قابلة للنقر --> <a href="https://google.com"> <img src="logo.png" alt="Go to Google"> </a>
👁️ Browser Preview

↑ A real image rendered from an internet URL

♿

Always write an alt attribute on images. It describes the image for screen readers (blind users) and appears when the image fails to load. Never leave it empty unless the image is purely decorative.

اكتب دائماً سمة alt على الصور. تصف الصورة لقارئات الشاشة (المستخدمون المكفوفون) وتظهر عند فشل تحميل الصورة. لا تتركها فارغة إلا إذا كانت الصورة زخرفية بحتة.

05
Forms & Inputs
النماذج وحقول الإدخال
English

Forms are how users interact with your site — login pages, search boxes, contact forms, sign-ups. HTML provides many input types to capture exactly the data you need.

العربية

النماذج هي طريقة تفاعل المستخدمين مع موقعك — صفحات تسجيل الدخول، مربعات البحث، نماذج الاتصال، التسجيل. يوفر HTML أنواع إدخال متعددة لالتقاط البيانات التي تحتاجها.

Complete Form Example / مثال نموذج كامل
<form action="/submit" method="POST"> <!-- Text input --> <label for="name">Full Name</label> <input type="text" id="name" name="name" placeholder="Your name" required> <!-- Email input --> <label for="email">Email Address</label> <input type="email" id="email" name="email" placeholder="you@example.com"> <!-- Dropdown --> <label for="level">Your Level</label> <select id="level" name="level"> <option value="beginner">Beginner</option> <option value="intermediate">Intermediate</option> </select> <!-- Textarea --> <label for="msg">Message</label> <textarea id="msg" name="msg" rows="4" placeholder="Write here..."></textarea> <button type="submit">Send Message</button> </form>

ℹ️

Always pair <label> with <input> using matching for and id attributes. This makes clicking the label focus the input — better UX and accessibility.

اقرن دائماً <label> مع <input> باستخدام سمتَي for وid المتطابقتين. هذا يجعل النقر على التسمية يركّز على حقل الإدخال — تجربة مستخدم وإمكانية وصول أفضل.

06
Semantic HTML — The Modern Approach
HTML الدلالي — المنهج الحديث
English

Semantic HTML means using the right tag for the right purpose. Instead of wrapping everything in <div>, modern HTML has meaningful tags like <header>, <nav>, <main>, <article>, <footer>. These help search engines, screen readers, and other developers understand your page.

العربية

HTML الدلالي يعني استخدام الوسم الصحيح للغرض الصحيح. بدلاً من تغليف كل شيء في <div>، يملك HTML الحديث وسوماً ذات معنى مثل <header> و<nav> و<main> و<article> و<footer>. تساعد محركات البحث وقارئات الشاشة والمطورين الآخرين على فهم صفحتك.

Page Layout with Semantic Tags — تخطيط الصفحة بالوسوم الدلالية

<header>
Logo, site title, nav bar
شعار، عنوان الموقع، شريط التنقل
<nav>
Navigation links menu
قائمة روابط التنقل
<main>
Primary page content
المحتوى الرئيسي للصفحة
<article>
Blog post / content
<section>
Thematic group
<aside>
Sidebar / related content
الشريط الجانبي / محتوى ذو صلة
<footer>
Copyright, links, contact
حقوق النشر، روابط، تواصل
❌ Old Way — الطريقة القديمة
<div class="header">...</div>
<div class="nav">...</div>
<div class="main">...</div>
<div class="footer">...</div>

Everything is a div. No meaning for browsers or Google.

كل شيء div. لا معنى للمتصفحات أو Google.

✅ Modern Way — الطريقة الحديثة
<header>...</header>
<nav>...</nav>
<main>...</main>
<footer>...</footer>

Meaningful tags. Better SEO, accessibility & readability.

وسوم ذات معنى. أفضل لـ SEO وإمكانية الوصول والقراءة.

🏆

Rule of thumb: if a tag has a name that describes what it contains (header, footer, nav, article), use it. Only use <div> and <span> when no semantic tag fits.

القاعدة الذهبية: إذا كان للوسم اسم يصف ما يحتويه (header, footer, nav, article) — استخدمه. استخدم <div> و<span> فقط عندما لا يناسب أي وسم دلالي.
