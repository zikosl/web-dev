1. First, think like a beginner developer

A developer is not someone who memorizes everything. A developer is someone who knows how to build, test, search, fix, and improve step by step.

In this course, mistakes are not a problem. Mistakes are proof that your brain is touching real code.

١. أولاً، فكّر كمطور مبتدئ

المطور ليس شخصاً يحفظ كل شيء. المطور هو شخص يعرف كيف يبني، يجرّب، يبحث، يصلح، ويحسّن خطوة بخطوة.

في هذا الكورس، الأخطاء ليست مشكلة. الأخطاء دليل أن عقلك بدأ يتعامل مع الكود الحقيقي.

Rule 1قاعدة ١

Do not memorize everything.
Understand the idea, then practice.

لا تحفظ كل شيء.
افهم الفكرة، ثم طبّق.

Rule 2قاعدة ٢

Read errors slowly.
The error message is not your enemy.

اقرأ الأخطاء بهدوء.
رسالة الخطأ ليست عدوك.

Rule 3قاعدة ٣

Organize your files.
Messy files create messy learning.

نظّم ملفاتك.
الملفات الفوضوية تجعل التعلم فوضوياً.

2. What is web development?٢. ما هو تطوير الويب؟

Web development means building things that run in a web browser: websites, landing pages, dashboards, online stores, portfolios, web apps, admin panels, and more.

When you open a website, your browser receives files, reads them, and shows the result on the screen.

تطوير الويب يعني بناء أشياء تعمل داخل المتصفح: مواقع، صفحات هبوط، لوحات تحكم، متاجر إلكترونية، بورتفوليو، تطبيقات ويب، ولوحات إدارة.

عندما تفتح موقعاً، يستقبل المتصفح ملفات، يقرأها، ثم يعرض النتيجة على الشاشة.

HTML

The structure: headings, paragraphs, buttons, links, images, forms.

الهيكل: عناوين، فقرات، أزرار، روابط، صور، ونماذج.

CSS

The design: colors, layout, spacing, responsive screens.

التصميم: الألوان، التخطيط، المسافات، والتجاوب مع الشاشات.

JavaScript

The behavior: clicks, menus, forms, data, dynamic changes.

السلوك: النقرات، القوائم، النماذج، البيانات، والتغييرات الديناميكية.

Frontend firstالواجهة الأمامية أولاً

This course starts with the part users see and touch: the frontend. Later, when the basics are strong, backend ideas become easier.

هذا الكورس يبدأ بالجزء الذي يراه المستخدم ويتفاعل معه: الواجهة الأمامية. لاحقاً، عندما تصبح الأساسيات قوية، ستصبح أفكار الخلفية أسهل.

3. Website, web app, frontend, backend٣. موقع، تطبيق ويب، واجهة أمامية، خلفية

Website

A website usually presents information: a company page, blog, restaurant menu, personal portfolio.

موقع Website

الموقع غالباً يعرض معلومات: صفحة شركة، مدونة، قائمة مطعم، أو بورتفوليو شخصي.

Web app

A web app lets users do more actions: login, save data, manage tasks, send messages, buy products.

تطبيق ويب Web App

تطبيق الويب يسمح للمستخدم بعمل أشياء أكثر: تسجيل الدخول، حفظ البيانات، إدارة المهام، إرسال الرسائل، أو الشراء.

Frontend

The visible part: layout, buttons, forms, navigation, animations, and user experience.

الواجهة الأمامية Frontend

الجزء المرئي: التخطيط، الأزرار، النماذج، التنقل، الحركة، وتجربة المستخدم.

Backend

The behind-the-scenes part: databases, authentication, servers, APIs, and security logic.

الخلفية Backend

الجزء الذي يعمل خلف الكواليس: قواعد البيانات، تسجيل الدخول، الخوادم، APIs، ومنطق الحماية.

Simple exampleمثال بسيط

In a login page, the input fields and button are frontend. Checking the password in a database is backend.

في صفحة تسجيل الدخول، حقول الإدخال والزر هي واجهة أمامية. التأكد من كلمة المرور داخل قاعدة بيانات هو خلفية.

4. PC basics that matter for coding٤. أساسيات الحاسوب المهمة للبرمجة

You already use a PC normally. Good. Now you need to use it like a developer: clear folders, clear names, visible file extensions, and no random project files everywhere.

أنت تستعمل الحاسوب بشكل عادي. ممتاز. الآن تحتاج أن تستعمله كمطور: مجلدات واضحة، أسماء واضحة، إظهار امتدادات الملفات، وعدم نشر ملفات المشاريع عشوائياً في كل مكان.

Files

A file is one saved item. Examples: index.html, style.css, logo.png.

الملفات

الملف هو عنصر محفوظ واحد. أمثلة: index.html، style.css، logo.png.

7. Windows setup steps٧. خطوات تجهيز ويندوز

Follow these steps in order. Do not rush. A clean setup saves hours of confusion later.

Common beginner problemمشكلة شائعة عند المبتدئين

If node -v or git -v does not work after installation, close VS Code and the terminal, then open them again. Sometimes Windows needs a fresh terminal session.

إذا لم يعمل الأمر node -v أو git -v بعد التثبيت، أغلق VS Code والطرفية ثم افتحهما من جديد. أحياناً يحتاج ويندوز جلسة طرفية جديدة.

8. Verify your setup with commands٨. تأكد من الإعداد بالأوامر

Open VS Code, then open the terminal inside VS Code. Run these commands one by one. The exact version numbers do not need to match your teacher's computer.

افتح VS Code، ثم افتح الطرفية داخل VS Code. شغّل هذه الأوامر واحداً تلو الآخر. أرقام الإصدارات لا يجب أن تكون مثل جهاز المدرّس تماماً.

node -v
npm -v
git -v

What does -v mean?

It means “version”. When you type node -v, you ask: “Which Node.js version is installed?”

ماذا يعني -v؟

يعني “version” أي الإصدار. عندما تكتب node -v فأنت تسأل: “ما إصدار Node.js المثبت؟”

What result is good?

If you see a version number, the tool is installed. If you see “not recognized”, the tool is missing or the terminal needs restart.

ما النتيجة الجيدة؟

إذا رأيت رقم إصدار، فالأداة مثبتة. إذا ظهرت رسالة “not recognized”، فالأداة غير مثبتة أو تحتاج إلى إعادة فتح الطرفية.

Useful Git identity commandsأوامر مفيدة لهوية Git

Later, Git needs your name and email to label your saved changes.

لاحقاً، يحتاج Git إلى اسمك وبريدك حتى يضعهما على التغييرات المحفوظة.

git config --global user.name "Your Name"
git config --global user.email "you@example.com"

9. What is the terminal?٩. ما هي الطرفية؟

The terminal is a place where you talk to your computer by typing commands. It looks scary at first, but in this course we will use simple commands only.

Think of it like a search box for actions: instead of clicking many menus, you type one clear instruction.

الطرفية هي مكان تتحدث فيه مع الحاسوب بكتابة أوامر. تبدو مخيفة في البداية، لكن في هذا الكورس سنستعمل أوامر بسيطة فقط.

تخيّلها كصندوق بحث للأفعال: بدل أن تضغط على قوائم كثيرة، تكتب تعليمة واضحة واحدة.

Beginner commands later

cd move between folders

dir list files on Windows

mkdir create a folder

أوامر بسيطة لاحقاً

Important rule

Do not copy random commands from the internet if you do not understand what they do.

قاعدة مهمة

لا تنسخ أوامر عشوائية من الإنترنت إذا لم تفهم ماذا تفعل.

10. Browser DevTools: your testing room١٠. أدوات المطور في المتصفح: غرفة الاختبار

The browser is not only for visiting websites. For a frontend developer, it is also a testing tool.

You will use DevTools to inspect HTML, test CSS, read console errors, check mobile screens, and understand network requests later.

المتصفح ليس فقط لزيارة المواقع. بالنسبة لمطور الواجهة الأمامية، هو أيضاً أداة اختبار.

ستستعمل أدوات المطور لفحص HTML، تجربة CSS، قراءة أخطاء Console، اختبار شاشات الهاتف، وفهم طلبات الشبكة لاحقاً.

اضغط F12، أو اضغط بزر الفأرة الأيمن على الصفحة واختر Inspect.

11. What are Node.js, npm, and Vite?١١. ما هي Node.js و npm و Vite؟

At the beginning, HTML files can open directly in the browser. But modern frontend projects often need tools. Node.js lets those tools run on your computer.

في البداية، يمكن فتح ملفات HTML مباشرة في المتصفح. لكن مشاريع الواجهة الأمامية الحديثة تحتاج غالباً إلى أدوات. Node.js يسمح لهذه الأدوات بالعمل على حاسوبك.

Node.js

A JavaScript runtime. For us, it helps run frontend tools locally.

Node.js

بيئة تشغيل JavaScript. بالنسبة لنا، تساعد على تشغيل أدوات الواجهة الأمامية محلياً.

npm

A package manager. It helps install JavaScript tools and libraries.

npm

مدير حزم. يساعد على تثبيت أدوات ومكتبات JavaScript.

Vite

A modern frontend tool we will use later to create faster development projects.

Vite

أداة حديثة للواجهة الأمامية سنستعملها لاحقاً لإنشاء مشاريع تطوير أسرع.

Do not worryلا تقلق

You do not need to master Node.js in Chapter 1. You only need to install it and understand why it exists.

لا تحتاج إلى إتقان Node.js في الفصل الأول. تحتاج فقط إلى تثبيته وفهم سبب وجوده.

12. Git and GitHub in simple words١٢. Git و GitHub بكلمات بسيطة

Git

Git saves the history of your project. It helps you see what changed, go back if needed, and work professionally.

Git

Git يحفظ تاريخ مشروعك. يساعدك على معرفة ما الذي تغيّر، الرجوع عند الحاجة، والعمل بطريقة احترافية.

GitHub

GitHub is a website where you can store Git projects online and share them with others.

GitHub

GitHub هو موقع يمكنك فيه حفظ مشاريع Git على الإنترنت ومشاركتها مع الآخرين.

Memory exampleمثال بسيط للتذكر

Git is like “save game history” for your project. GitHub is like “cloud storage for that history”.

13. Small talk: Can AI help me learn?١٣. حديث قصير: هل يساعدني الذكاء الاصطناعي؟

Yes. AI can explain errors, give examples, simplify hard words, and help you practice. But AI should not replace your learning.

The goal is not “AI writes everything for me.” The goal is “AI helps me understand while I build.”

نعم. يمكن للذكاء الاصطناعي أن يشرح الأخطاء، يعطي أمثلة، يبسط الكلمات الصعبة، ويساعدك على التدريب. لكن لا يجب أن يستبدل تعلمك.

الهدف ليس “الذكاء الاصطناعي يكتب كل شيء بدلاً مني”. الهدف هو “الذكاء الاصطناعي يساعدني على الفهم وأنا أبني”.

Good AI useاستخدام جيد للذكاء الاصطناعي

“Explain this error like I am a beginner.”
“Give me 3 practice tasks for HTML forms.”

“اشرح هذا الخطأ كأنني مبتدئ.”
“أعطني ٣ تمارين على HTML forms.”

Bad AI useاستخدام سيئ للذكاء الاصطناعي

“Build the whole project for me, and I will not read it.”

“ابنِ المشروع كاملاً بدلاً مني، ولن أقرأه.”
