01
What is Web Development?
ما هو تطوير الويب؟
English

Web development is the process of building websites and web applications that live on the internet. Think of every website you've ever visited — someone built that using code. It's one of the most in-demand skills in the world right now.

العربية

تطوير الويب هو عملية بناء مواقع وتطبيقات الويب التي تعيش على الإنترنت. فكّر في كل موقع زرته من قبل — شخص ما بناه باستخدام الكود. إنها واحدة من أكثر المهارات طلباً في العالم الآن.

🌐
Frontend Dev
تطوير الواجهة الأمامية

What the user sees and interacts with. Buttons, colors, layouts, animations.

ما يراه المستخدم ويتفاعل معه. أزرار، ألوان، تخطيطات، رسوم متحركة.

⚙️
Backend Dev
تطوير الواجهة الخلفية

The "engine" behind the site. Databases, servers, user logins, data processing.

المحرك خلف الموقع. قواعد بيانات، خوادم، تسجيل دخول، معالجة البيانات.

🔗
Full-Stack Dev
تطوير متكامل

A developer who does both — the full picture from UI to database.

مطور يفعل كليهما — الصورة الكاملة من الواجهة إلى قاعدة البيانات.

💡

This course focuses on Frontend first. You'll learn HTML, CSS, and JavaScript — the three core languages of the web. Everything else builds on top of these.

هذا الكورس يركز على الواجهة الأمامية أولاً. ستتعلم HTML وCSS وJavaScript — اللغات الثلاث الأساسية للويب. كل شيء آخر يبنى فوق هؤلاء.

✏️ Quick Check
اختبار سريع

What does a Frontend developer mainly build?

ماذا يبني مطور الواجهة الأمامية بشكل رئيسي؟

02
How the Internet & Browser Work
كيف يعمل الإنترنت والمتصفح
English

When you type a website address, your browser sends a request through the internet to a server. That server sends back files (HTML, CSS, JS), and your browser reads them and shows you the webpage. It all happens in milliseconds!

العربية

عندما تكتب عنوان موقع، يرسل متصفحك طلباً عبر الإنترنت إلى خادم. يُرسل الخادم ملفات (HTML، CSS، JS)، ويقرأها متصفحك ويعرض لك صفحة الويب. كل هذا يحدث في ميلي ثانية!

📄
HTML — Structure
HTML — الهيكل

The skeleton of a webpage. Headings, paragraphs, buttons, images — all defined in HTML.

هيكل صفحة الويب. العناوين، الفقرات، الأزرار، الصور — كل ذلك يُعرَّف في HTML.

🎨
CSS — Style
CSS — التصميم

Makes things look good. Colors, fonts, sizes, spacing, animations.

يجعل الأشياء تبدو جميلة. ألوان، خطوط، أحجام، مسافات، رسوم متحركة.

⚡
JavaScript — Behavior
JavaScript — السلوك

Makes pages interactive. Clicks, popups, forms, live updates, apps.

يجعل الصفحات تفاعلية. نقرات، نوافذ، نماذج، تحديثات مباشرة، تطبيقات.

📦
The Browser
المتصفح

Chrome, Firefox, Safari, Edge — they all read these three languages and display webpages.

Chrome، Firefox، Safari، Edge — تقرأ هذه اللغات الثلاث وتعرض صفحات الويب.

ℹ️

Use Google Chrome as your main browser during this course. Its Developer Tools (F12) are the best in the industry for learning and debugging.

استخدم Google Chrome كمتصفحك الرئيسي خلال هذا الكورس. أدوات المطور فيه (F12) هي الأفضل في الصناعة للتعلم واكتشاف الأخطاء.

03
PC Requirements & Specs
متطلبات ومواصفات الحاسوب
English

The good news: you don't need an expensive machine to start web development. A mid-range PC or laptop from the last 5–7 years will work just fine. Here's what you need:

العربية

الخبر الجيد: لا تحتاج جهازاً غالياً لبدء تطوير الويب. حاسوب أو لابتوب متوسط المستوى من آخر 5-7 سنوات سيعمل بشكل ممتاز. إليك ما تحتاجه:

Component Minimum Recommended المكوّن
RAM 4 GB 8 GB+ ذاكرة الوصول العشوائي
Storage 50 GB free SSD 256 GB+ مساحة التخزين
Processor Intel i3 / AMD Ryzen 3 i5/i7 or Ryzen 5/7 المعالج
Operating System Windows 10 Windows 11 / macOS / Linux نظام التشغيل
Screen 13" 15"+ or external monitor الشاشة
Internet Any connection Stable broadband الإنترنت
✅

Windows or Mac? Both work perfectly. Most tutorials work on either. If you're on Windows, we recommend installing Windows Terminal for a better command-line experience.

ويندوز أم ماك؟ كلاهما يعمل بشكل مثالي. معظم الدروس تعمل على الاثنين. إذا كنت على ويندوز، ننصح بتثبيت Windows Terminal لتجربة سطر أوامر أفضل.

⚠️

Chromebooks: Limited support. Some tools don't work well on ChromeOS. If possible, use a Windows or Mac machine.

Chromebooks: دعم محدود. بعض الأدوات لا تعمل بشكل جيد على ChromeOS. استخدم جهاز Windows أو Mac إن أمكن.

05
Setting Up VS Code + Extensions
إعداد VS Code والإضافات
English

VS Code is powerful out of the box, but extensions make it even better. These are small add-ons that improve your coding experience. Here are the must-haves for web development.

العربية

VS Code قوي من البداية، لكن الإضافات تجعله أفضل. هي إضافات صغيرة تحسن تجربة الكتابة. إليك الإضافات الأساسية لتطوير الويب.

Must-Have Extensions — إضافات أساسية

Prettier – Code Formatter
Auto-formats your code to look clean. Essential. / يُنسّق كودك تلقائياً ليبدو نظيفاً.
Live Server
Opens your webpage live in browser as you code. / يفتح صفحتك في المتصفح مباشرة أثناء الكتابة.
ESLint
Highlights JavaScript errors before you run code. / يبرز أخطاء JavaScript قبل تشغيل الكود.
Auto Rename Tag
Rename an HTML opening tag and closing updates automatically. / تغيير العلامة الافتتاحية يُحدّث الختامية تلقائياً.
GitLens
Supercharges Git inside VS Code. See who changed what. / يُحسّن Git داخل VS Code. اعرف من غيّر ماذا.
indent-rainbow
Colors your indentation levels — makes nested code readable. / يلوّن مستويات المسافة لقراءة الكود المتداخل.

Installing Extensions — تثبيت الإضافات

1
Open VS Code
افتح VS Code

Launch the application after installing it from code.visualstudio.com

شغّل التطبيق بعد تثبيته من code.visualstudio.com

2
Go to Extensions Panel
اذهب إلى لوحة الإضافات

Click the Extensions icon on the left sidebar, or press Ctrl + Shift + X

انقر على أيقونة الإضافات في الشريط الجانبي، أو اضغط Ctrl + Shift + X

3
Search and Install
ابحث وثبّت

Type the extension name, click it from results, then click the green "Install" button.

اكتب اسم الإضافة، انقر عليها من النتائج، ثم انقر زر "Install" الأخضر.

4
Set Prettier as Default Formatter
اجعل Prettier المُنسّق الافتراضي

Press Ctrl + Shift + P → type "Format Document" → choose Prettier. Also enable "Format on Save" in Settings.

اضغط Ctrl + Shift + P → اكتب "Format Document" → اختر Prettier. فعّل أيضاً "Format on Save" في الإعدادات.

VS Code — Useful Keyboard Shortcuts / اختصارات لوحة المفاتيح
# Open integrated terminal / فتح الطرفية المدمجة

# Quick file open / فتح ملف سريع

06
File System & Folder Structure
نظام الملفات وهيكل المجلدات
English

Before you start a project, organize your files properly. A messy file structure = a headache later. Every web project has a standard structure — learn it now and follow it always.

العربية

قبل بدء أي مشروع، نظّم ملفاتك بشكل صحيح. الهيكل الفوضوي = صداع لاحقاً. لكل مشروع ويب هيكل معياري — تعلّمه الآن واتّبعه دائماً.

Standard Project Structure — هيكل مشروع معياري

📁 my-first-project/ ← root folder / المجلد الجذر
📁 css/
📄 style.css ← all your styles
📁 js/
📄 script.js ← all your scripts
📁 images/
🖼️ logo.png
🖼️ hero.jpg
📄 index.html ← always the homepage / الصفحة الرئيسية دائماً
📄 about.html
📄 README.md ← describe your project
📌
Golden Rules
القواعد الذهبية

• index.html is always the homepage
• No spaces in file names (use - instead)
• Always lowercase file names
• Keep one folder per project

• index.html دائماً هو الصفحة الرئيسية
• لا مسافات في أسماء الملفات (استخدم - بدلاً)
• أسماء الملفات دائماً بأحرف صغيرة
• مجلد واحد لكل مشروع

🛠️
Opening a Project in VS Code
فتح مشروع في VS Code

Method 1: Drag the project folder onto VS Code.
Method 2: File → Open Folder
Method 3: Right-click folder → "Open with VS Code"

الطريقة 1: اسحب مجلد المشروع على VS Code.
الطريقة 2: File → Open Folder
الطريقة 3: انقر بزر الفأرة الأيمن → "Open with VS Code"

💡

Create a "Projects" folder on your Desktop or Documents and keep all your web projects inside it. Example: C:\Users\YourName\Desktop\Projects\

أنشئ مجلد "Projects" على سطح المكتب أو في المستندات واحتفظ بجميع مشاريع الويب فيه. مثال: C:\Users\YourName\Desktop\Projects\
